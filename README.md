# 📂 Система сдачи работ

Веб-приложение для сдачи студенческих работ с автоматическим сохранением файлов по категориям и группам.

---

## 🚀 Быстрый запуск

### 1. Скачать и распаковать архив с проектом

### 2. Запустить `start.bat`

Для запуска необходимо дважды кликнуть по файлу `start.bat`. Скрипт автоматически выполнит следующие действия:

- Проверит наличие установленного Python (при отсутствии — скачает и установит автоматически)
- Создаст виртуальное окружение
- Установит все необходимые библиотеки
- Запустит сервер
- Откроет сайт в браузере

### 3. Готово

Сайт будет доступен по адресу: **http://localhost:5000**

## 🛠️ Настройка сайта

Все настройки производятся путём редактирования текстовых файлов в папке `content/`.

### Заголовок страницы
Файл: `content/title.txt`  
Любой текст, который будет отображаться вверху страницы.

### Информационный блок
Файл: `content/info.txt`  
Обычный текст. Ссылки (начинающиеся с `http://` или `https://`) автоматически становятся кликабельными.

**Пример содержимого `info.txt`:**
Добро пожаловать в систему сдачи работ!
Загружайте файлы в соответствии с выбранной категорией.
Информация на сайте: `https://example.com`

> ℹ️ Например, текст `https://example.com` автоматически станет кликабельной ссылкой.
> ℹ️ В примере используется `https://example.com` — это демонстрационная ссылка. На реальном сайте нужно указывать действующий адрес.

### Текст в выпадающем списке
Файл: `content/select_title.txt`  
Текст-подсказка, отображаемая в выпадающем списке перед выбором категории.

Пример: `Выберите тип работы`

### Файлы для скачивания
Папка: `content/files/`  
Любые файлы, помещённые в эту папку (PDF, DOCX, изображения и т.д.), появятся на главной странице со ссылкой для скачивания.

## 🌙 Тёмная и светлая тема

Приложение поддерживает два цветовых режима: **светлый** (по умолчанию) и **тёмный**.

### Переключение темы
Для переключения используется круглая кнопка в правом верхнем углу страницы (☀️/🌙). Выбранная тема сохраняется в браузере и не сбрасывается после перезагрузки страницы.

### Настройка иконки переключения
Иконка для кнопки переключения темы находится в папке `static/` и называется `theme.png`.

**Чтобы заменить иконку:**
1. Подготовить изображение (рекомендуемый размер — 30×30 или 60×60 пикселей)
2. Сохранить его под именем `theme.png`
3. Поместить файл в папку `static/`, заменив существующий

> ⚠️ Иконка используется только для отображения в кнопке. Сама тема переключается автоматически и не зависит от содержимого картинки.

### Как выглядит переключение

| Действие | Результат |
|----------|-----------|
| Клик по кнопке | Цветовая схема меняется на противоположную |
| Повторный клик | Возврат к предыдущей схеме |
| Перезагрузка страницы | Выбранная тема сохраняется |

## 📂 Управление категориями (темами)

Категории соответствуют папкам внутри `uploads/`.

| Действие | Как выполнить |
|----------|---------------|
| **Добавить категорию** | Создать новую папку в `uploads/` (например, `Конкурс`) |
| **Удалить категорию** | Удалить папку из `uploads/` |
| **Переименовать категорию** | Переименовать папку в `uploads/` |

**Важно:** после изменения категорий необходимо перезапустить `start.bat`.

### Особенности категории «Другое»

Категория «Другое» **всегда присутствует** в выпадающем списке, даже если папки `Другое` нет в папке `uploads/`. Это сделано для того, чтобы можно было создавать новые темы «на лету», не создавая папки заранее.

- Если папка `Другое` существует в `uploads/` — файлы сохраняются в неё (в подпапку с введённым названием)
- Если папки `Другое` нет — она будет создана автоматически при первой загрузке

Таким образом, папка `Другое` не обязательна, но её наличие не вредит.

## 🧑‍🎓 Правила работы с категориями

| Категория / Папка | Поля для заполнения | Куда сохраняется файл |
|-------------------|---------------------|----------------------|
| Любая папка в формате `БУКВЫ(заглавные русские)-ЦИФРЫ(2)-ЦИФРА` (например, `ИС-24-1`) | только ФИО | `uploads/ИС-24-1/` |
| `Экзамен`, `Экзамен-Зачёт`, `Экзамен-Зачет`, `Зачёт-Экзамен`, `Зачет-Экзамен`, `Зачёт`, `Зачет`, `Практика` | Группа + ФИО | `uploads/Категория/Группа/` |
| `Чемпионат` | Номер участника + ФИО | `uploads/Чемпионат/` |
| `Другое` | Название темы + ФИО | `uploads/Другое/Название_темы/` |

## 🔧 Возможные проблемы и решения

### Python не найден
Скрипт `start.bat` автоматически скачает и установит Python. Требуется дождаться завершения установки.

### Иконка вкладки не отображается
Рекомендуется очистить кеш браузера (`Ctrl + Shift + Delete`) или открыть сайт в режиме инкогнито.

### Файлы не сохраняются
Необходимо проверить, что папка `uploads/` существует и доступна для записи.

### Технические детали тёмной темы
Тёмная тема реализована через CSS-переменные и класс `dark` на элементе `<body>`:

```css
:root {
    --bg: #f4f4f5;      /* светлый фон */
    --text: #111827;    /* тёмный текст */
}

body.dark {
    --bg: #12201e;      /* тёмный фон */
    --text: #f9fafb;    /* светлый текст */
}
```

```javascript
// JavaScript сохраняет выбранную тему в localStorage
localStorage.setItem("theme", "dark");

// При загрузке страницы проверяется сохранённое значение
if (localStorage.getItem("theme") === "dark") {
    document.body.classList.add("dark");
}
```

# 📂 Система сдачи работ

Веб-приложение для сдачи студенческих работ с автоматическим сохранением файлов по категориям и группам.

---

## 🚀 Быстрый запуск

### 1. Скачать и распаковать архив с проектом

### 2. Запустить `start.bat`

Для запуска дважды кликните по файлу `start.bat`. Скрипт автоматически выполнит следующие действия по порядку:

| Шаг | Что делает `start.bat` |
|-----|------------------------|
| 1 | Проверяет, установлен ли Python. Если нет — скачивает и устанавливает **Python 3.14.5** автоматически |
| 2 | Проверяет, свободен ли порт 5000. Если занят — находит следующий свободный (5001, 5002...) |
| 3 | Создаёт виртуальное окружение `venv` (если его нет) |
| 4 | Устанавливает библиотеки: Flask, markupsafe |
| 5 | Запускает сервер и открывает сайт в браузере |

> ✅ **Всё, что нужно для работы, `start.bat` делает сам. Ничего устанавливать вручную не требуется.**

## 🖥️ Что происходит в консоли (чёрном окне)

После запуска `start.bat` откроется чёрное окно командной строки. **Не закрывайте его** — это работает сервер.

**Пример вывода:**

```
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
      СЕРВЕР ЗАПУЩЕН НА ПОРТУ 5000!
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Для этого компьютера:
http://localhost:5000
http://127.0.0.1:5000

Для других компьютеров в сети:
http://192.168.1.142:5000
```

- **IP-адрес** (в примере `192.168.1.142`) может быть другим. Смотрите его в консоли.
- **Если порт 5000 занят**, `start.bat` найдёт другой (5001, 5002...). В консоли будет, например, `СЕРВЕР ЗАПУЩЕН НА ПОРТУ 5001!`

### Доступ с других компьютеров

Все компьютеры должны быть **подключены к одной локальной сети** (один Wi-Fi, один роутер или один Ethernet-коммутатор).
На другом компьютере введите в браузере: `http://IP_из_консоли:ПОРТ_из_консоли`

> ⚠️ Если порт занят, используйте порт из консоли. Компьютер с сервером должен быть включён, а `start.bat` — запущен. На некоторых компьютерах может потребоваться разрешить доступ в брандмауэре Windows.

### Другие сообщения в консоли

| Что написано | Что значит |
|-------------|------------|
| `"GET / HTTP/1.1" 200` | Кто-то открыл сайт ✅ |
| `"POST / HTTP/1.1" 200` | Файл успешно загружен ✅ |
| `404` | Страница не найдена |
| `500` | Ошибка в коде сервера |

### Остановка сервера
Просто закройте чёрное окно.

## 🛠️ Настройка сайта

Все настройки производятся путём редактирования текстовых файлов в папке `content/`.

### Заголовок страницы
Файл: `content/title.txt`  
Любой текст, который будет отображаться вверху страницы.

### Информационный блок
Файл: `content/info.txt`  
Обычный текст. Ссылки (начинающиеся с `http://` или `https://`) автоматически становятся кликабельными.

**Пример содержимого `info.txt`:**
```
Добро пожаловать в систему сдачи работ!
Загружайте файлы в соответствии с выбранной категорией.
Информация на сайте: `https://example.com`
```

> ℹ️ Например, текст `https://example.com` автоматически станет кликабельной ссылкой.
> ℹ️ В примере используется `https://example.com` — это демонстрационная ссылка. На реальном сайте нужно указывать действующий адрес.

### Текст в выпадающем списке
Файл: `content/select_title.txt`  
Текст-подсказка, отображаемая в выпадающем списке перед выбором категории.

Пример: `Выберите тип работы`

### Файлы для скачивания

Папка: `content/files/`

Любые файлы, помещённые в эту папку (PDF, DOCX, изображения и т.д.), появятся на главной странице со ссылкой для скачивания.

> ⚠️ **Важно:** В этой папке **не должно быть** файлов-заглушек (`.gitkeep`, `.gitkeep.txt`). Если они там есть — они отобразятся на сайте как файлы для скачивания. **Удалите их**.
>
> Если папка пустая — на сайте ничего не отображается. Это нормально. Как только вы положите туда реальный файл (инструкцию, макет), он появится автоматически.

---

### О служебных файлах

В папке `uploads/` может быть файл `.gitkeep`. Он нужен только для того, чтобы Git сохранил пустую папку в репозитории.

- На работу программы он **не влияет**.
- Его можно **удалить** — папка `uploads/` всё равно создастся автоматически, если её нет, при первой загрузке файла через сайт.

## 🌙 Тёмная и светлая тема

Приложение поддерживает два цветовых режима: **светлый** (по умолчанию) и **тёмный**.

### Переключение темы
Для переключения используется круглая кнопка в правом верхнем углу страницы (☀️/🌙). 

**Выбранная тема сохраняется и не сбрасывается:**
- ✅ При перезагрузке страницы
- ✅ При закрытии и повторном открытии браузера
- ✅ **При перезапуске `start.bat` (даже если порт изменился)**
- ✅ При обновлении страницы (`F5`)

### Настройка иконки переключения
Иконка для кнопки переключения темы находится в папке `static/` и называется `theme.png`.

**Чтобы заменить иконку:**
1. Подготовить изображение (рекомендуемый размер — 30×30 или 60×60 пикселей)
2. Сохранить его под именем `theme.png`
3. Поместить файл в папку `static/`, заменив существующий
> ⚠️ Иконка используется только для отображения в кнопке. Сама тема переключается автоматически и не зависит от содержимого картинки.

### Как выглядит переключение

| Действие | Результат |
|----------|-----------|
| Клик по кнопке | Цветовая схема меняется на противоположную |
| Повторный клик | Возврат к предыдущей схеме |
| Перезагрузка страницы | Выбранная тема сохраняется |
| Закрытие и повторное открытие браузера | Выбранная тема сохраняется |
| Перезапуск `start.bat` | Выбранная тема сохраняется (работает через куки) |

## 📂 Управление категориями (темами)

Категории соответствуют папкам внутри `uploads/`.

| Действие | Как выполнить |
|----------|---------------|
| **Добавить категорию** | Создать новую папку в `uploads/` (например, `Конкурс`) |
| **Удалить категорию** | Удалить папку из `uploads/` |
| **Переименовать категорию** | Переименовать папку в `uploads/` |

**Важно:** после изменения категорий **не нужно перезапускать `start.bat`**. Достаточно просто обновить страницу (`F5` или `Ctrl + F5`).

### Особенности категории «Другое»

Категория «Другое» **всегда присутствует** в выпадающем списке, даже если папки `Другое` нет в папке `uploads/`. Это сделано для того, чтобы можно было создавать новые темы «на лету», не создавая папки заранее.

- Если папка `Другое` существует в `uploads/` — файлы сохраняются в неё (в подпапку с введённым названием)
- Если папки `Другое` нет — она будет создана автоматически при первой загрузке

Таким образом, папка `Другое` не обязательна, но её наличие не вредит.

## 🧑‍🎓 Правила работы с категориями

| Категория / Папка | Поля для заполнения | Куда сохраняется файл |
|-------------------|---------------------|----------------------|
| Любая папка или папка в формате `БУКВЫ(заглавные русские)-ЦИФРЫ(2)-ЦИФРА` (например, `ИС-24-1`) | только ФИО | `uploads/ИС-24-1/` |
| `Экзамен`, `Экзамен-Зачёт`, `Экзамен-Зачет`, `Зачёт-Экзамен`, `Зачет-Экзамен`, `Зачёт`, `Зачет`, `Практика` | Группа + ФИО | `uploads/Категория/Группа/` |
| `Чемпионат` | Номер участника + ФИО | `uploads/Чемпионат/Участник_номер/` |
| `Другое` | Название темы + ФИО | `uploads/Другое/Название_темы/` |

## 📝 Как формируются имена файлов

При загрузке файла система автоматически переименовывает его, чтобы избежать путаницы и обеспечить уникальность.

### Формат имени файла

| Категория | Формат имени файла | Пример |
|-----------|-------------------|--------|
| Экзамен / Зачёт / Практика | `Группа_ФИО_оригинал_дата.расш` | `ИС-24-1_Иванов_Иван_отчет_2025-06-04_18-30-00.pdf` |
| Чемпионат | `Номер_ФИО_оригинал_дата.расш` | `5_Иванов_Иван_решение_2025-06-04_18-30-00.pdf` |
| Другое | `ФИО_оригинал_дата.расш` | `Иванов_Иван_курсовая_2025-06-04_18-30-00.docx` |
| Папка-группа (например, `ИС-24-1`) | `ФИО_оригинал_дата.расш` | `Иванов_Иван_доклад_2025-06-04_18-30-00.pdf` |

### Что означает каждая часть

| Часть | Описание |
|-------|----------|
| `Группа` / `Номер` | Идентификатор группы или номер участника (добавляется автоматически) |
| `ФИО` | Фамилия и имя, введённые пользователем (пробелы заменяются на `_`) |
| `оригинал` | Оригинальное имя файла (без расширения) |
| `дата` | Дата загрузки в формате `ГГГГ-ММ-ДД` |
| `время` | Время загрузки в формате `ЧЧ-ММ-СС` |
| `расш` | Расширение файла (например, `.pdf`, `.docx`) |

### Почему это удобно

- **Уникальность:** дата и время в имени исключают конфликт имён
- **Контроль времени:** по имени файла видно, когда сдана работа (важно для чемпионатов и дедлайнов)
- **Безопасность:** специальные символы удаляются автоматически через `secure_filename`

## 🔧 Возможные проблемы и решения

### Python не найден
Скрипт `start.bat` автоматически скачает и установит Python. Требуется дождаться завершения установки.

### Иконка вкладки не отображается
Рекомендуется очистить кеш браузера (`Ctrl + Shift + Delete`) или открыть сайт в режиме инкогнито.

### Файлы не сохраняются
Необходимо проверить, что папка `uploads/` существует и доступна для записи.

## 👩‍💻 Для разработчиков

### Изменение внешнего вида
Файл `templates/index.html` содержит CSS и JavaScript. Редактирование этого файла позволяет изменить внешний вид и поведение сайта.

### Добавление новой категории с особыми полями
В файле `templates/index.html` в объект `topicFields` необходимо добавить новую категорию. Примеры уже присутствуют в коде.

### Технические детали тёмной темы
Тёмная тема реализована через CSS-переменные и класс `dark` на элементе `<body>`:

```css
:root {
    --bg: #f4f4f5;      /* светлый фон */
    --text: #111827;    /* тёмный текст */
}

body.dark {
    --bg: #12201e;      /* тёмный фон */
    --text: #f9fafb;    /* светлый текст */
}
```

```javascript
// JavaScript сохраняет выбранную тему в куки (чтобы работало при смене порта)
setCookie("theme", "dark");

// При загрузке страницы проверяется сохранённое значение в куки
if (getCookie("theme") === "dark") {
    document.body.classList.add("dark");
}
```
